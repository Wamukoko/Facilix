# Facilix — Property & Facility Management Web App

## Product Vision

Build **Facilix**, a modern, enterprise-grade, self-hosted **Property & Facility Maintenance Management Platform** designed for property managers, estate managers, facility managers, landlords, maintenance teams, contractors, and service providers.

Facilix should centralize property assets, maintenance operations, work orders, preventive maintenance, suppliers, inventory, budgets, documents, and reporting into one intelligent platform.

The product should feel like a combination of a **modern property management system, CMMS, maintenance command center, and tenant service portal** — with a clean corporate interface optimized for real-world property operations.

## Brand

**Name:** Facilix
**Meaning:** Facility + Intelligence / Management

**Brand personality:** Professional, reliable, intelligent, operational, modern, efficient, trustworthy.

Avoid making the interface look like a generic construction or industrial CMMS. Facilix should specifically feel designed for **modern property and estate management**.

Use a sophisticated corporate visual language with:

* Clean layouts
* Generous whitespace
* Strong information hierarchy
* Professional typography
* Subtle cards and borders
* Clear status indicators
* Data-rich dashboards
* Responsive design
* Desktop-first operations dashboard with excellent tablet/mobile support

# UX Requirements

The interface must prioritize **speed of operation**.

A maintenance supervisor should be able to create a work order in seconds.

A technician should be able to open a task, understand the problem, view the asset, complete the checklist and close the task with minimal navigation.

A property manager should immediately understand the operational condition of the entire portfolio from the dashboard.

Use:

* Command palette
* Keyboard shortcuts
* Quick actions
* Bulk actions
* Smart filters
* Saved views
* Contextual actions
* Responsive tables
* Drawer-based detail panels
* Confirmation dialogs for destructive actions

Avoid excessive modal windows and unnecessary form fields.

# Visual Design Direction

Create a premium B2B SaaS aesthetic.

The design should communicate:

**Control + Reliability + Intelligence + Efficiency**

Use a restrained corporate color system with a strong primary brand color, neutral backgrounds, clear success/warning/error states, and high-contrast typography.

Use charts and visualizations carefully. Avoid decorative graphics that do not contribute to operational understanding.

Cards should be clean and compact rather than oversized.

Tables should be highly usable because the application will contain large operational datasets.

# Final Product Standard

Facilix should not look like a simple CRUD administration system.

It should feel like a **professional property operations command center** capable of managing thousands of units, buildings, assets, maintenance tasks and service requests.

Prioritize:

**Operational visibility → Fast execution → Accountability → Cost control → Preventive maintenance → Data-driven management.**

Build the interface first with realistic sample data, then connect it to the PostgreSQL/PostGIS backend and REST API.

The finished application should be responsive, accessible, scalable, self-hostable, modular, and production-ready.
